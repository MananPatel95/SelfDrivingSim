# Graphics assets

City look textures in `game/src/render/cityTextures.ts` are original procedural
canvas / DataTexture work for this project. Released as **CC0 1.0 Universal**
(public domain dedication).

Ego sedan GLB remains Kenney CC0 (`game/public/models/sedan-sports.glb`).

No Quaternius packs are vendored in this change. Street lamps, facades, asphalt
wear, sidewalk tiles, grass clumps, window lights, and the 16³ LUT are generated
at runtime.

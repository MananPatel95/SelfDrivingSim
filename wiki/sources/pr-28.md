# PR #28 — Revert F3 overlay extract; skip roadside poles in hazard brake

## What changed

Restored the pre-[[pr-26]] F3 HUD: `renderBEVHeatmaps` calls `runWaabiStack` again. Deleted `bevOverlay.ts`, `occupancyPaint.ts`, `f3Perf.test.ts`, and `bench:views`. PR #27 ABS braking is unchanged.

`obstacleAhead` and the Slowing banner skip roadside statics (poles, trees, buildings, signs). A corner pole ~7 m ahead no longer full-brakes a turn. Contact with a pole still collides.

## Why

After #26/#27 the ego stopped at 0 km/h mid left-turn with `Slowing: pole ID 23 at 7m`. The planner already ignored poles; the sim hazard path did not. #26 did not write that path; it only made F3 the view in use. Revert + pole skip.

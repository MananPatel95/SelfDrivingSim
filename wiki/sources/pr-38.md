# PR #38 — North-American stop / yield sign visuals

Visual-only follow-up. `signPose` positions and `decideIntersection` are unchanged.

- Stop: MUTCD flat-top red octagon, white border, white **STOP**, grey pole.
- Yield: inverted triangle, thick red border, white field, red **YIELD**.
- Blades live in the local YZ plane (normal +X) so `meshYawForHeading(sign.yaw)` faces oncoming traffic (`yaw = heading + π`).
- Shared canvas textures + geometries; upright signs are three `InstancedMesh`es (pole / stop / yield). Fallen signs hide the instance and spawn a `createSignGroup` that reuses the same assets.
- Lidar, Tesla vision, and HUD counts still read world-entity `id` / `classType` / bounding boxes.
- **YIELD** is a smaller centred string near the wide top of the white triangle (does not clip the red border).
- Corner streetlights are offset 16 m along the curb (`cornerStreetLampOffsets`) so a lamp post is not stacked on the sign pole. `signPose` is unchanged.

Planner, spawn, `updateVehicle`, `removeGround`, `createBEVOccupancyFromAgents`, and `simHotPath.ts` were not edited.
